# Full interlacing windows for ordered set partitions at bounded ratio

Bowen Zuo, East China University of Science and Technology.

Extract the TeX source archive into an empty directory, then run
`python3 -B reproduce.py --output main.pdf --log build.log`.
Use TeX Live 2026 and the Latin Modern fonts for byte-identical output.
If pdfLaTeX is outside `PATH`, set `PDFLATEX` to its absolute path.

The formal entry is `OrderedPartitions.HardRodWindowVerified`. Extract
`ordered-partitions-bounded-window-source.zip` from the verification
archive and run its separate dependency-lock and replay instructions.
The earlier adjacent theorem is available through its version DOI.
[Earlier preprint](https://doi.org/10.5281/zenodo.24570914)
